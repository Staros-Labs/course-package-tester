# Roadmap

Near-term priorities:

- collect agency install and launch feedback from the unsigned v1.0.2 release
- zip import hardening
- better manifest diagnostics
- Tester Report improvements
- signed Windows releases using the documented Authenticode workflow after certificate cost is approved
- additional SCORM and xAPI-style inspection features

See [v1.0.2 Release Notes](./v1.0.2-release.md) for the shipped patch-release scope and remaining follow-ups.

Later possibilities:

- macOS desktop package
- Linux desktop package
- deeper package compatibility checks
- optional UI automation smoke tests
