# v1.1.0 Release Notes

v1.1.0 is an unsigned usability release for external course-package review.

## Release URL

```text
https://github.com/Staros-Labs/course-package-tester/releases/tag/v1.1.0
```

## Windows Artifact

```text
CoursePackageTester_Windows_x64_v1.1.0.zip
```

## Signature Status

v1.1.0 is unsigned. Windows may show a publisher or SmartScreen warning.

## Shipped Changes

- Adds a dismissible first-run guide for the recommended review workflow.
- Adds recent package shortcuts for recently launched or imported packages.
- Adds clearer zip import failure categories and suggestions.
- Adds a Feedback Summary JSON export with prompts, Tester Report data, and diagnostics.
- Keeps the local-only network posture with no telemetry, uploads, or external services.

## Validation

- `npm test`
- `npm run package:windows:zip`

- GitHub Actions CI on `v1.1.0`
- CodeQL on `main`

## Remaining Follow-Ups
