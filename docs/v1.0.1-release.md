## Signature Status

v1.0.1 is unsigned. Windows may show a publisher or SmartScreen warning.

Windows code signing remains documented and ready, but is deferred until a certificate or signing provider is available.

## Shipped Changes

- Added signed-release operations and documentation for future Authenticode signing.
- Added agency handoff guidance.
- Updated package dependencies through Dependabot.
- Updated manifest parsing for `@xmldom/xmldom` 0.9 compatibility.
- Kept the app local-only with no telemetry, upload, cloud, or auto-update behavior.
