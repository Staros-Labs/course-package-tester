# v1.0.1 Backlog

Target: small unsigned hardening release after the public v1.0.0 baseline.

Status: shipping unsigned. Windows code signing remains documented and ready, but is deferred until a certificate is available.

## Priority

1. Unsigned v1.0.1 release
   - Publish the dependency, manifest parser, signing-ops, and handoff documentation updates.
   - State unsigned status in release notes.
   - Include the SHA256 checksum.

2. Agency install feedback
   - Capture any SmartScreen, extraction, launch, or folder-selection friction.
   - Convert reproducible issues into focused fixes.

3. Zip import edge cases
   - Improve messaging for zips with multiple possible launch files.
   - Improve diagnostics for packages with missing or malformed manifests.

4. Tester Report polish
   - Review report wording after first external use.
   - Add only fields that help diagnose launch/import/runtime issues.

5. Signed Windows release path
   - Configure signing certificate or HSM-backed signing secrets when the fee is approved.
   - Run the `Signed Windows Release` workflow.
   - Verify Authenticode status is `Valid`.
   - Publish a signed zip and checksum.

## Release Gate

v1.0.1 should not ship until:

- `npm test` passes
- Windows package build passes
- GitHub Actions CI passes on `main`
- release tag CI passes
- CodeQL passes
- signature status is accurately documented
